The Problem

Split-Brain Desynchronization
breaks every agent fleet

Traditional architectures split agent memory across two separate systems. A single network timeout creates permanent, unrecoverable memory corruption.

Developer API

One endpoint. One transaction.
Both memories persisted.

Send agent state and raw text context together. StateVault generates the Bedrock embedding and commits everything atomically to CockroachDB.

bash — POST /v1/sync 
curl -X POST https://api.statevault.site/v1/sync \
  -H "x-api-key: <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id":          "atlas_prod_01",
    "state_key":         "active_workflow_state",
    "state_value":       {"step": 3, "status": "blocking_ip"},
    "raw_text_memory":  "Blocked IP range 192.168.1.0/24 — anomalous spike us-east-1."
  }'

# Response: {"status":"success","session_id":"<uuid>","synchronized":true}
